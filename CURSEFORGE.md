**WoW AI Chat – talk to an AI in a normal WoW chat tab.**

Adds a chat tab (default name "WoW AI") where you chat with Claude, ChatGPT/Codex, a local Ollama/LM Studio model or any
OpenAI-style API. Answers appear right in the tab, no reload, endless conversation. Also: a small in-game browser window.

**Important – this addon needs a free companion program** (WoW addons cannot talk to the internet themselves):
download it from <GITHUB-LINK einsetzen>, double-click `WoW-AI.bat`, done. It finds your game folder and
an AI that is already on your PC. Windows only, game in windowed/borderless mode. The program only reads the pixels of the
game window; it never touches game memory. Optional tools (mouse and keyboard, computer access for the AI) are off by default and only switched on by you.

**What you can do (all from the in-game menu `/wac`)**
- **AI setup** – a window over the game: search this PC for AIs, load or unload one at any time, pick the model from the AI's own list,
  see the last real answer live, press "Test now" for a real test question.
- **Harness** – answer as the WoW helper (knows your character and game version) or as your own AI with its own instructions, memory and skills.
  Works for the chat, the CLI chat and the CLI window separately.
- **CLI chat / CLI window** – the real command line tool of Claude Code or Codex inside the game, with scrolling, copy and paste.

Commands: `/wac` menu, `/browser [url]`, `/c question`.
